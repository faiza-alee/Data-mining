# Storyboard & Shot List — Episode 1

## Style
- Clean, bright colors; friendly rounded icons; big readable text.
- Aspect ratio: 16:9 (1920x1080).
- Font suggestion: Poppins or Nunito; large headings.

## Shots
1) 0:00–0:05 Title Card
- Visual: Animated lightbulb + friendly robot wave
- Text: AI for Kids — What is AI?
- Motion: Fade-in; slight scale pop

2) 0:05–0:25 Hook Montage
- Visuals: Face unlock icon; YouTube/playlist thumbnails; mic icon
- Motion: Quick cuts synced to beats

3) 0:25–0:35 Welcome Lower-Third
- Visual: Lower-third bar with "Episode 1"
- Text: Made for Classes 6–10

4) 0:35–1:10 Definition
- Visual: Icons: brain, image, chat bubble, decision tree
- Motion: Each icon animates on when named

5) 1:10–2:00 AI ⟶ ML ⟶ DL
- Visual: Three nested boxes animation
- Motion: Zoom into each box with labels

6) 2:00–3:00 Learning Flow
- Visual: Data → Patterns → Model → Predictions → Test → Improve
- Motion: Arrow flows; elements highlight in sequence

7) 3:00–3:40 Real-life Tiles
- Visual: 2x2 grid of cards (Recs, Assist, Translate, Camera)
- Motion: Hover lift

8) 3:40–4:20 Ethics
- Visual: Balanced scale; shield; heart
- Motion: Gentle float

9) 4:20–5:30 Activity
- Visual: Sticky notes with doodles; two boxes: Face / Not Face

10) 5:30–5:45 Recap
- Visual: Checklist icons in a row

11) 5:45–6:00 Next Episode + CTA
- Visual: Browser window mock; Subscribe button pulse

## Assets List
- Icons: brain, camera, chat, mic, shield, scale, heart, robot, lightbulb
- Cards: video thumbnail placeholders, sticky notes
